# 🏋️ Gym Management System

## 📌 Project Overview

The **Gym Management System** is a relational database project developed using **MySQL**.

The system is designed to manage important gym operations such as member registration, memberships, payments, attendance, trainers, gym classes, class bookings, and equipment.

This project demonstrates practical SQL and database management concepts including table creation, relationships, constraints, joins, aggregate functions, subqueries, GROUP BY, LEFT JOIN, and data analysis queries.
